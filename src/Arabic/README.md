# نظام التعرف على الوجوه – Face Recognition

## مقدمة
هذا المشروع يسمح بتسجيل الأشخاص والتعرف عليهم باستخدام صور الوجه فقط. يعتمد على نموذج MobileFaceNet.tflite للحصول على embeddings للوجوه ومقارنتها.

## المجلدات والملفات
- `models/MobileFaceNet.tflite` : نموذج TFLite للتعرف على الوجه.
- `extract_embedding_ar.py` : استخراج الـ embeddings من الصور.
- `enroll_person_ar.py` : تسجيل شخص جديد أو تحديث بياناته في قاعدة البيانات.
- `recognize_image_ar.py` : التعرف على الأشخاص باستخدام صورة واحدة.
- `README.md` : هذا الملف.

## كيفية تسجيل الأشخاص
1. جهز 5 صور على الأقل لكل شخص.
2. نفذ الأمر التالي:
```bash
python enroll_person_ar.py <اسم الشخص> <صورة1.jpg> <صورة2.jpg> ... <صورة5.jpg>
```

3. سيتم حساب الـ embeddings وحفظها في قاعدة البيانات face_db.pkl.

## التعرف على الأشخاص
لتعرف على شخص من صورة واحدة:
```bash
python recognize_image_ar.py <مسار الصورة>
```
سيقوم البرنامج بمقارنة الصورة بالـ embeddings المسجلة وسيطبع الاسم إذا كان معروفًا أو يطبع "الشخص غير معروف" إذا لم يوجد تطابق.
